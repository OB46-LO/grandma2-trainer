# grandMA2 Trainer v1.8

Interaktives Lernprogramm für die **grandMA2**-Lichtkonsole: im Browser, auf PC, Mac und iPad.

## Was drin ist
- **40 Lektionen** von leicht bis schwer: Tasten, Command Line, Auswahl, Werte, Groups, Presets, Cues, Executor, Programmer-Werkzeuge, Effekte, Moving Heads, Show-Szenarien und eine Abschlussprüfung
- **Simulator** mit gezeichneter Konsole, Encodern und einer Bühne mit 12 Scheinwerfern (Dimmer, Farbe, Pan, Tilt, Zoom, Gobo)
- **Effekt-Editor**: Nachbau der Effekt-Tabelle mit Form, Speed, Phase, Width, Groups, Blocks und Wings
- **Lua für grandMA2**: 15 Lektionen mit eingebautem Lua-Interpreter und nachgebautem `gma`-API
- Tasten-Quiz, Tasten-Lexikon, Hilfe-Knopf

## Benutzen
Einfach `index.html` im Browser öffnen. Es muss nichts installiert werden.

Online über GitHub Pages: im Repository unter **Settings → Pages → Branch: main / (root)** einschalten. Danach läuft der Trainer unter `https://<dein-name>.github.io/<repo-name>/`.

## Hinweis
Das ist ein inoffizielles Lernprogramm und steht in keiner Verbindung zu MA Lighting. „grandMA2“ ist eine Marke der MA Lighting Technology GmbH. Die Simulation ist vereinfacht: Für die echte Konsole gilt immer das offizielle Handbuch.
